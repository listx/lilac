#+title: Release Notes

* Versions

** v0.1.0.5 (WIP)

Improvements:

  - Block ancestors are no longer just arrow symbols. Instead we print the full
    name of the block (and the Org doc where it's from if it's external), inside
    the hidden metadata area.

    We also filter out the redundant ~name~ and ~tangle~ metadata keys because they
    are already displayed in the [[id:c5a40150-b1e1-4794-bd82-18bb4319185a][Name and tangle path]] part of the block at the
    very top.

  - Binaries are now pushed to Cachix.

  - Hanging indentation for glossary terms.

  - Reduce excess whitespace in the woven output.

      - Less vertical spacing between list items.

      - Reduced left margin.

  - Various doc improvements.

Changes:

  - Make the footer advertise Lilac's homepage, not repo URL.
