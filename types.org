#+title: Types

We define the types we use in one place.

* =Lilac.Types= module
:PROPERTIES:
:ID:       af82950f-ec4a-46e1-9af5-995222cd35e3
:END:

This module defines the core types and some helper functions (those named with a
~default*~ prefix). Most of the discussions of the actual types themselves are
done in [[id:e16dd5c7-0a63-4c52-afe9-744fdf853643][the Org parser]], because that module requires these types to perform the
parsing (and it is in this capacity that most of these types first come into
existence in the system). For this reason, many of the code blocks are defined
(and discussed) there.

* Miscellaneous helpers

** Org ID (OID)
:PROPERTIES:
:ID:       5908cefc-0e82-41a5-84ac-1c8c826f5e62
:END:

Org IDs (see [[id:5df15f17-c630-4ddf-bade-66084c430a07::newtype:OID][newtype:OID]], [[id:f8254d58-7a3d-4595-a265-e0d6255e6ab5][Links]], and [[id:f8254d58-7a3d-4595-a265-e0d6255e6ab5::data:LinkOid][data:LinkOid]]) are UUIDs underneath. The
functions here manipulate this type.

[[f:fromWords]] constructs an ~OID~ from two 64-bit words.

#+name: f:fromWords
#+begin_src haskell
fromWords :: Word64 -> Word64 -> OID
fromWords w1 w2 = OID $ fromWords64 w1 w2
#+end_src

[[f:fromText]] constructs a ~Maybe OID~ from text.

#+name: f:fromText
#+begin_src haskell
fromText :: Text -> Maybe OID
fromText t = case Data.UUID.Types.fromText t of
  Just uuid -> Just $ OID uuid
  Nothing -> Nothing
#+end_src

[[instance:Show OID]] avoids printing the ~OID~ text because it's simpler to just have
the raw UUID by itself.

#+name: instance:Show OID
#+begin_src haskell
instance Show OID where
  show (OID uuid) = Prelude.show uuid
#+end_src

The [[f:nilOid]] is a special zero-value ~OID~. We use it for things like the
[[id:6cf4d5a5-ec4a-426e-8549-0a899ad77729::f:defaultOrgParserState][f:defaultOrgParserState]] and also in many of the [[id:409c6e54-59b9-4aa3-bd72-7ac3dd42ed66::All test cases][test cases]] for parsing.

#+name: f:nilOid
#+begin_src haskell
nilOid :: OID
nilOid = fromWords 0 0
#+end_src

** ~GPath~, an ~OsPath~ wrapper
:PROPERTIES:
:ID:       2d98229c-e318-434b-916b-364c04021306
:END:

[[newtype:GPath]] is a custom type that *guarantees* that it can only contain a
~FilePath~ which can be converted (without errors) into a valid ~OsPath~. It is
named ~GPath~ to mean "guaranteed path".

#+name: newtype:GPath
#+begin_src haskell
type GPath :: Type
newtype GPath = GPath FilePath
  deriving stock (Eq, Ord, Generic, Show)
  deriving anyclass (ToJSON)
  deriving newtype (Hashable)
#+end_src

Similar to [[id:01da95fe-ba23-4481-9833-428423392f5f::instance:ToJSONKey LinkOid][instance:ToJSONKey LinkOid]], we want to encode and decode ~GPath~ values
in a succinct way. Because this is a ~newtype~ wrapper, by default ~Data.Aeson~ will
try to write it as ~"GPath" \"...\""~ in JSON, which is ugly. To simplify this we
have custom ~ToJSONKey~ and ~FromJSONKey~ instances.

[[instance:ToJSONKey GPath]] tells ~Data.Aeson~ to only write the ~FilePath~ part of the
~GPath~.

#+name: instance:ToJSONKey GPath
#+begin_src haskell
instance ToJSONKey GPath where
  toJSONKey = toJSONKeyText $ \(GPath p) -> T.pack p
#+end_src

Both [[instance:FromJSON GPath]] and [[instance:FromJSONKey GPath]] understand how to
parse a ~GPath~ from a ~Text~ value. The ~FromJSONKey~ instance also requires a
~FromJSON~ instance, which is why we have both of them here.

#+name: instance:FromJSONKey GPath
#+begin_src haskell
instance FromJSONKey GPath where
  fromJSONKey = FromJSONKeyTextParser $ \t -> do
    pure . GPath $ T.unpack t
#+end_src

#+name: instance:FromJSON GPath
#+begin_src haskell
instance FromJSON GPath where
  parseJSON = withText "GPath" $ \t -> do
    pure . GPath $ T.unpack t
#+end_src

[[f:encodeGPath]] is the only way one is allowed to construct a [[newtype:GPath]].

#+name: f:encodeGPath
#+begin_src haskell
encodeGPath :: (MonadFail m) => FilePath -> m GPath
encodeGPath fp
  | Just osp <- P.encodeUtf fp,
    P.isValid osp =
      pure $ GPath fp
  | otherwise = fail $ "invalid file path: " <> show fp
#+end_src

[[f:decodeGPath]] takes a ~GPath~ and converts it back into the ~FilePath~ that it is
based on.

#+name: f:decodeGPath
#+begin_src haskell
decodeGPath :: GPath -> FilePath
decodeGPath (GPath fp) = fp
#+end_src

[[f:emptyGPath]] is an empty ~GPath~.

#+name: f:emptyGPath
#+begin_src haskell
emptyGPath :: GPath
emptyGPath = GPath ""
#+end_src

*** Succinct construction

In tests and other scenarios, we want to be able to succinctly construct ~GPath~
values without being encumbered by the monadic type of [[f:encodeGPath]]. For this
purpose we have a separate internal-only module which exposes the ~GPath~ constructor.

** Protocols

The [[f:protocolsWeb]] are the typical protocols found in links on the
internet.

#+begin_src haskell
protocolsWeb :: [Text]
protocolsWeb =

      "https",

** Marking characters
:PROPERTIES:
:ID:       3b072b1b-c63e-4fca-ab56-9388d11aa3c0
:END:

Marking characters are used in [[id:d0f60631-8b30-4ae1-992d-49c7b0ea38fb][Tables]] as special characters (see [[https://orgmode.org/manual/Advanced-features.html][this page]] for
more information). See [[id:d0f60631-8b30-4ae1-992d-49c7b0ea38fb::f:tableCellParser][f:tableCellParser]] and [[id:6c10afe2-2714-4e85-9121-e96a36d27ba4::f:weaveTable][f:weaveTable]] for how Lilac deals
with them.

#+name: f:markingChars
#+begin_src haskell
markingChars :: [Char]
markingChars = "#*" <> markingCharsInvisible
#+end_src

Some marking characters are purely for metadata and signal entire rows that are
not meant to be displayed to the user directly. These are defined separately.

#+name: f:markingCharsInvisible
#+begin_src haskell
markingCharsInvisible :: [Char]
markingCharsInvisible = "!^_$/"
#+end_src
