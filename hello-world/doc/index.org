#+title: Introduction

This is a sample, starter ~index.org~ file. It has some basic configuration to get
you started.

* Project layout

The configuration files here assumes that there is a ~doc~ folder which houses all
Org files (which we tangle and weave). This naturally leads to a [[id:c395c828-9422-47f0-a560-36aaf5b6c1f7][Makefile]] which
sits at the project root folder, from which we execute ~lilac~ to tangle files
anywhere in the project root, and also to weave HTML files back into the ~doc~
folder.

Note that this structure is arbitrary; you could easily have the Makefile inside
the ~doc~ folder if you wish.

* Project configuration

#+header: :tangle hello-world/.lilac.json
#+begin_src json
{
    "name": "Hello World",
    "homepage": "https://localhost",
    "repo": "https://localhost",
    "version": "",
    "nonTangledPathspecs": [ (ref:nonTangledPathspecs)
        ":(exclude,top).gitmodules",
        ":(exclude,top)LICENSE",
        ":(exclude,top)doc/*.org",
        ":(exclude,top)doc/*.html",
        ":(exclude,top)doc/css",
        ":(exclude,top)doc/js"
    ]
}
#+end_src

The ~nonTangledPathspecs~ [[(nonTangledPathspecs)]] is used by Lilac's ~lint~
subcommand, which checks for any differences between what is tangled and what is
tracked by Git. These two sets of files should mostly overlap. Any files that
are intentionally *not* tangled by Lilac should be listed in ~nonTangledPathspecs~.
These are fed to ~git-ls-files~ to ignore tracked files that are not tangled by
Lilac.

* Makefile
:PROPERTIES:
:ID:       c395c828-9422-47f0-a560-36aaf5b6c1f7
:END:

#+name: Makefile
#+header: :tangle hello-world/Makefile
#+begin_src makefile
org_files = \
	doc/index.org # (ref:Makefile-org_files)

obj_files = $(org_files:%.org=%.lobj) # (ref:Makefile-obj_files)

archive_file = doc/hello-world.larc # (ref:Makefile-archive)

all: tangle weave lint
.PHONY: all

$(obj_files) &: $(org_files) # (ref:Makefile-obj-compilation)
	lilac compile $?
	touch $(obj_files)

$(archive_file): $(obj_files) # (ref:Makefile-archive-creation)
	lilac archive $^ --out-file $@

tangle: $(archive_file) # (ref:Makefile-tangle)
	lilac tangle $< --out-dir . # (ref:Makefile-tangle-out-dir)
	touch tangle

weave: $(archive_file) # (ref:Makefile-weave)
	lilac weave $< --out-dir doc --write-css --write-js
	touch weave

lint: $(archive_file) # (ref:Makefile-lint)
	lilac lint $<
	touch lint

clean:
	rm -rf \
		$(archive_file) \
		$(obj_files)
.PHONY: clean

<<git-orderfile-gitconfig>>
#+end_src

[[(Makefile-org_files)]] tracks all Org files which we want to expose to Lilac. You
could very well add additional Org files to this list, as your project grows
beyond this Hello World example.

The Org files are compiled by Lilac into ~*.lobj~ intermediate files
[[(Makefile-obj_files)]] [[(Makefile-obj-compilation)]], before being combined
[[(Makefile-archive-creation)]] into a single ~doc/hello-world.larc~ archive
[[(Makefile-archive)]].

The Lilac subcommands ~tangle~ [[(Makefile-tangle)]], ~weave~ [[(Makefile-weave)]], and ~lint~
[[(Makefile-lint)]] all make use of the archive.

** A note on tangle paths

When tangling code blocks, note that by convention the tangle path is always
interpreted to be relative to the project root, not where the Org file is
located. This is because we pass the current directory to Lilac with ~--out-dir .~
[[(Makefile-tangle-out-dir)]]. This makes it much easier to move around code blocks
across Org files (without having to update the relative path).

If you change the ~--out-dir~ argument to another folder, Lilac will tangle code
blocks relative to that folder.

* Git

** ~.gitignore~

Ignore hidden files [[(ignore-hidden)]], but don't ignore some that we explicitly
tangle such as ~.gitattributes~.

#+header: :tangle hello-world/.gitignore
#+begin_src gitignore
 # (ref:ignore-hidden)
,**/.*

!**.gitattributes
!**.gitignore
!**.git-orderfile
doc/*.lobj
doc/*.larc
lint
tangle
weave
#+end_src

The ~*.lobj~ and ~*.larc~ files are generated by Lilac, so ignore them too. The
~lint~, ~tangle~, and ~weave~ files are sentinel files used by the Makefile, so ignore
them too.

** ~.gitttributes~

As the HTML files are generated (woven) by Lilac, ignore them from diffs. The
same goes for CSS and JS files which are generated by Lilac.

#+header: :tangle hello-world/.gitattributes
#+begin_src txt
doc/*.html -diff
doc/css/default.css -diff
doc/js/lilac.js -diff
#+end_src

** Git orderfile

Make ~git-diff~ show the Org files first, because they serve as the source of
truth.

#+name: git-orderfile
#+header: :tangle hello-world/.git-orderfile
#+begin_src txt
# Org files
doc/index.org
,*.org
#+end_src

As there is no standard filename for this, you have to tell Git to use it explicitly.

#+name: git-orderfile-gitconfig
#+begin_src makefile
gitconfig:
	git config diff.orderfile .git-orderfile
.PHONY: gitconfig
#+end_src
